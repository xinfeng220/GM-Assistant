## 三、Phase 1 平台搭建

### 3.1 项目结构（最终）

```
/
├── agent_core/                  # 核心框架
│   ├── __init__.py
│   ├── orchestrator.py          # 扫描 skills/，动态加载 skill_manifest，注册工具
│   ├── tool_registry.py         # 工具注册中心（read/write_internal/write_external）
│   ├── safety.py                # 安全网关：check_permission()
│   ├── logger.py                # 统一日志 + 敏感信息脱敏 + 近期日志缓冲
│   └── memory.py                # 会话历史（内存）
├── skills/email/                # 邮件技能
│   ├── __init__.py
│   ├── skill_manifest.py        # 自描述：SKILL_META + get_tools() + get_status()
│   ├── mail_fetcher.py          # IMAP 拉取；未配置时 Mock 样例（8 封，覆盖四档紧急度）
│   ├── email_classifier.py      # litellm 分类 + 关键词规则兜底
│   ├── ui_page.py               # Streamlit 页面：刷新 → 分组 → 展开详情
│   └── prompts/classification.py  # 分类系统提示词
├── pages/01_邮件处理.py          # 转发到 skills.email.ui_page.render()
├── main.py                      # 总览页：技能状态/工具计数/安全模式/最近日志
├── config.py                    # 全局配置（.env 读取）
├── .env.example                 # 环境变量示例
├── requirements.txt
├── .gitignore
└── 需求文档.md                  #（原有，未改动结构）
```

### 3.2 核心机制

- **技能插件架构**：新技能只需在 `skills/` 建目录 + `skill_manifest.py`（声明 SKILL_META / get_tools / get_status）+ `ui_page.py`，即可被 orchestrator 自动发现。单技能加载失败不阻塞其他技能（status=error）。
- **安全网关**：read 放行；write_internal 需 UI 确认；write_external 默认禁用（需 `ENABLE_WRITE_EXTERNAL=true`）。Phase 1 仅注册两个 read 工具。
- **Mock 模式**：IMAP 未配置 → 内置 8 封样例邮件；LLM 未配置 → 关键词规则分类。无凭据可端到端演示。
- **日志安全**：统一格式 `[时间] [模块] [级别] 消息`；自动脱敏邮箱与密码/密钥字段；邮件正文绝不写入日志；`redact()` 独立可测。

## 六、遇到的问题与解决

| 问题 | 原因 | 解决 |
| :--- | :--- | :--- |
| `email.message` 无属性 | `email.message` 子模块未显式导入 | `import email.message` |
| 日志脱敏断言失败 | 测试预期与实现（归一化分隔符为 `=`）不一致 | 修正测试断言为 `password=***` |
| 控制台中文乱码 | Windows 控制台默认 cp936 | logger.py 中 `sys.stdout.reconfigure(encoding="utf-8")` |
| `conda run` 报 UnicodeEncodeError | conda run 自身用 GBK 重打输出时遇到 ✅ 字符崩溃（conda bug） | 改用直接调用 `D:\conda_envs\GM-Assistant\python.exe`，绕过 conda run |
| 页面文件名含 emoji | 用户要求文件名不含 emoji | 重命名 `pages/01_📧_邮件处理.py` → `pages/01_邮件处理.py` |
| Mock 样例无「普通」档 | 样例正文含"方案"命中「重要」关键词 | 调整样例正文避开关键词，四档齐全 |
