## 二、结构化重构：动机与设计决策

### 2.1 动机

Phase 1 + LangGraph 迁移后，架构存在拓展性摩擦：技能契约隐式、数据全裸 dict、config 单一扁平类、LLM 调用分散、route 无命名空间、无观测。本次以 gaokao_tutor 项目架构为**模式参考**（仅借鉴，不并入），改造为**能力平台形态**：email 只是 `src/capabilities/` 下的第一个能力，后续可挂载更多能力（gaokao 辅导、日程、搜索等）。

### 2.2 已确认的设计决策

| 决策 | 结论 |
| :--- | :--- |
| 平台形态 | `src/core/` 平台运行时（与具体能力无关）+ `src/capabilities/<name>/` 能力模块（manifest + tools + graph + ui_page） |
| 前端栈 | 保留 Streamlit，新增图执行可视化（零依赖手写 SVG） |
| 数据模型 | Pydantic v2（Email / Classification / EmailClassified，`from` 别名往返） |
| 配置 | `config/settings.yaml`（非敏感）+ `.env`（密钥）+ `Config.get_prompt()` 模板缓存 |
| LLM | `src/core/llm.py` 统一 `completion` + `invoke_with_fallback`（LLM 优先、规则兜底） |
| 路由 | manifest 声明裸 `ROUTES`，orchestrator 前缀成命名空间 route（`email.refresh`） |
| 契约校验 | orchestrator `_validate_manifest`：坏 manifest → `status="error"`，不阻塞其他能力 |
| 持久化 | `checkpointer.py` 工厂抽象（现 MemorySaver，后续可换 Postgres） |
| 观测 | `tracing.py` TraceRecorder + `@traced` + `safe_call` 工具审计 + `visualizer.py` SVG + `pages/01_visualization.py` |
| git 提交 | 本次用户明确委托：重构全部提交、最终合并、推送由我执行 |

设计文档：`docs/superpowers/specs/2026-08-07-backend-restructure-design.md`
实施计划：`docs/superpowers/plans/2026-08-07-backend-restructure.md`（10 任务，含完整代码）

## 五、遇到的问题与解决

| 问题 | 原因 | 解决 |
| :--- | :--- | :--- |
| 计划 Task 2 代码块 `Email(from=...)` 语法错误 | `from` 是 Python 保留字 | 实现者等值改法：`Email(**{"from": ...})` / `from_=`（`populate_by_name` 同一别名路径），评审确认行为一致 |
| Task 7 新测试使全量套件顺序跑挂 `test_pages` | 新 `Orchestrator().scan()` 调用 `registry.clear()` 清掉全局 email 工具 | conftest 新增 autouse `_isolate_registry` fixture（快照/恢复注册中心） |
| Task 9 计划自相矛盾：可视化页 NODES 用 `email.fetch` 名 | `@traced` 记录 `fn.__name__`（`fetch_node`），高亮永不命中 | 控制器裁定：NODES 名改用 `fetch_node`/`classify_node`（label 保持友好），并在 ledger 记档 |
| Task 10 计划片段 `tracer.get_last_run()` 无法生效 | tracer 进程内、`begin_run/end_run` 仅在 UI 层；裸 `agent.invoke` 不记录 | 实现者用单进程 begin_run→invoke→end_run 包裹正确验证（2 节点/2 工具/无兜底），未改源码 |
| 最终评审：`TRACING_ENABLED`/`RECENT_MAXLEN` 读入却无人消费 | Task 9 接口声明消费但未接线（死配置） | 修复：`begin_run` 门控 `TRACING_ENABLED` + 单例 `recent_maxlen=config.TRACING_RECENT_MAXLEN` + 新增门控测试 |
| `EnterWorktree` 原生工具失败（base branch 解析失败） | 环境限制 | 退回手动 `git worktree add .claude/worktrees/backend-restructure -b backend-restructure HEAD` |
| `.claude/worktrees/` 未被 gitignore | 目录新建后未加入忽略 | 加入 `.gitignore`（提交 `e863792`） |
| 中文文件名（用户新规「不可以用中文」） | 页面 / 需求文档 / 开发日志原为中文名 | 全部改名英文（`git mv`）+ 同步引用（测试路径 / README / docstring），35 测试保持绿 |
